📊 Research SSI Calculator

Advanced Semantic Stability Analysis for Multi-Answer Research Questions

📋 How to use:
  • Add 2 or more answer sets (A, B, C, D, etc.)
  • Each answer set should contain answers in format: A1x) answer text or Question 1: answer
  • Each answer should be on a new line
  • The calculator will automatically extract and group answers by question number
  • SSI will be calculated for each question individually and across all questions
⚠️ Backend Required: Python backend must be running on localhost:5000
