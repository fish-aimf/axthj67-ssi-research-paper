📊 Research SSI Calculator

Advanced Semantic Stability Analysis for Multi-Input Text Comparison

📋 How to use:
  • Add 2 or more input sets (A, B, C, D, etc.)
  • Each input set should contain texts with each text on a new line
  • Each line will be treated as one input (Input 1, Input 2, etc.)
  • SSI will be calculated for each input position individually and across all inputs
  • Enable "Strip prefixes" option to remove question numbers/labels (Q1a:, A1b:, etc.)
⚠️ Backend Required: Python backend must be running on localhost:5000
