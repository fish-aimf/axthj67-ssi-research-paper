🎯 Semantic Stability Outlier Detector

Analyze each set individually (target: SSI ≥ 0.95)

📋 How to use:
  • Paste variations for each set (A, B, C, D, E) - one variation per line
  • No labels needed - just paste the raw text variations
  • Click "Analyze Set" for each set individually
  • Target: SSI ≥ 0.95 (failing sets highlighted in RED)
  • Outlier variations are marked for replacement
Example format (no labels needed):
Mary would like to go to the park
Mary wants to go to the park
Mary wishes to visit the park
Mark ate bananas

⚠️ Backend Required: Python backend must be running on localhost:5000
