🎯 Cross-Set Question Stability Checker

Test the same question across different sets (A, B, C, D, E) - Target: SSI ≥ 0.90

📋 How to use:
  • Set A contains Q1a, Q2a, Q3a, Q15a, Q28a...
  • Set B contains Q1b, Q2b, Q3b, Q15b, Q28b...
  • Works with ANY format: Q1a: text | Q1a) text | Q1a. text | Q1a text
  • The tool will group by question number (Q1, Q2, Q15, Q28, etc.)
  • SSI is calculated for each question across all sets
  • Questions with SSI < 0.90 are highlighted in RED for manual review
Example formats (all work!):
Set A: Q1a: Mary likes parks | Q2a) The sky is blue
Set B: Q1b. Mary wants parks | Q2b The sky appears blue
Set C: Q1c) Mary visits parks | Q2c: Sky looks blue

⚠️ Backend Required: Python backend must be running on localhost:5000
