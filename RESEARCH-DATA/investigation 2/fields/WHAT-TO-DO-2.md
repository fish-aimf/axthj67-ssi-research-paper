# Investigation 2 — Instructions for Getting Answers

This README explains **exactly how to use ChatGPT** to get answers in the required format for **Investigation 2**.
Follow the steps carefully to avoid formatting errors.

---

## How to Ask ChatGPT

### Step 1: Open a New Chat

* Go to **ChatGPT**
* Click **New Chat**
* Make sure it is a **fresh conversation** so there is no previous context

---

### Step 2: Paste the Question Set

* Copy **one full question set**
* Paste it into the chat **together with the prompt below**

---

### Step 3: Paste the Prompt

Copy **everything inside the text box below** and paste it into ChatGPT **without changing anything**.

```
Paste 1 question set here
Question set over here 

Reply to these questions in this exact format without additional words
A1x)
A2x)
A3x)
A4x)
Changing only the letter in front from Q for question to A for answer where x depends on the question set. 
Give your answer in a text box for easy copying and pasting ``
```

---

## Important Rules

* ✅ **Do not modify the prompt**
* ✅ Paste **only one** question set at a time
* ✅ Answers must follow the format **exactly**
* ❌ No explanations
* ❌ No extra words
* ❌ No missing or extra numbering

---

## Required Answer Format (Example)

The response **must look exactly like this**:

```
A11)
A12)
A13)
A14)
```

* Only the **letter changes from `Q` to `A`**
* The value of **x depends on the question set**

---

## Final Reminder

If the format is incorrect, the answers may be **rejected**.
Always double-check formatting before copying and submitting.

---

**Follow these instructions exactly to get clean, copy-paste-ready answers.**
