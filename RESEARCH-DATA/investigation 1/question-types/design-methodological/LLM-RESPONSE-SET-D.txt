A1d) Conduct a study with two high school calculus classes: one using traditional lecture-based teaching and the other using problem-based learning. Independent variable: teaching method. Dependent variable: student performance on standardized calculus tests. Controls: same curriculum content, teacher experience, class duration, and student demographics. Evaluation: pre- and post-test scores, improvement rates, and student engagement surveys.

A2d) Set up a flat mirror on a protractor-marked board. Equipment: laser pointer, protractor, ruler, screen. Procedure: shine laser at mirror at various incidence angles (e.g., 10°–80°), measure reflected angle each time. Independent variable: incidence angle. Dependent variable: reflection angle. Controls: same mirror, laser intensity, measurement distance. Analysis: plot incidence vs. reflection angles to confirm the law of reflection.

A3d) Select a chemical reaction (e.g., sodium thiosulfate with hydrochloric acid). Vary temperature (e.g., 20°C, 30°C, 40°C, 50°C). Measure reaction rate by time to precipitate formation or using spectrophotometry. Controls: same concentrations, volumes, and stirring rate. Replicate each condition thrice. Analysis: graph reaction rate vs. temperature and calculate activation energy.

Analysis: compare mean growth across fertilizers using ANOVA.
