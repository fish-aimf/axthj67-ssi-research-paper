# Research Data

## Overview
Provide a brief description of the dataset, its purpose, how it was collected, and any important notes.

This section contains 3 investigations:
- Investigation 1 examines the correlation between question types and SSI.
- Investigation 2 examines the correlation between subjects and SSI.
- Investigation 3 investigates the correlation between temperature and SSI.

## Structure
This folder contains the data used in the research project. Use the links below to navigate to specific subdirectories.

- [Investigation 1](./investigation%201/)
  
  **Description:**  
  Investigation 1 examines the correlation between question types and SSI.  
  This directory contains:
  - A file listing the question types identified in the study (closed factual, computational/numerical, procedural/how-to, conceptual/definition, analytical/multistep reasoning, interpretive/contextual, evaluative/normative, design/methodological).
  - Five prompt files for each question type, along with the corresponding AI responses.
  - Analysis files
  - A raw results and discussion file summarizing observations and findings.
